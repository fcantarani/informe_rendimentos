Processador de Informe de Rendimentos

Ferramenta de automação para divisão de PDFs em lote e envio individualizado de informes de rendimentos por e-mail via AWS SES.

Python 3.11+ AWS SES Oracle DB PyMuPDF · pypdf pydantic-settings

O sistema recebe um ou mais arquivos PDF contendo informes de rendimentos em lote, identifica o CPF ou CNPJ de cada destinatário em cada página, gera um arquivo PDF individual por destinatário e, em seguida, consulta o banco Oracle para obter nome e e-mail e realiza o envio automático pelo serviço Amazon Simple Email Service (SES).

ℹ
O projeto é executado inteiramente via linha de comando e não possui interface web. Toda configuração é feita por variáveis de ambiente carregadas de um arquivo .env.

Principais responsabilidades

EtapaEntradaSaídaMódulo responsável
Split PDF(s) em input/ PDFs individuais em output/ src/pdf_processor.py
Identificação Texto extraído de cada página CPF ou CNPJ formatado src/identifier.py
Consulta Oracle CPF/CNPJ (somente dígitos) nome e email src/database.py
Envio de e-mail PDF + dados do cliente E-mail enviado via SES src/email_sender.py

Decisões de design

DecisãoJustificativa
Modo thin do oracledb Elimina a necessidade de instalar o Oracle Instant Client — só drivers Python puros.
AWS SES por send_raw_email Permite controle total dos cabeçalhos MIME e inclusão de anexos binários.
Exportação de settings como singleton Garante leitura única do .env e ponto único de verdade para configurações.
Herança de identificador entre páginas Cobre layouts multi-página onde CPF/CNPJ aparece só na primeira página do informe.
MODO_TESTE Redireciona todos os e-mails para um endereço de teste sem alterar o código.

Fluxo de Execução

O sistema opera em duas fases independentes que podem ser executadas em conjunto ou separadamente.

Fase 1 — Split de PDFs

1
Descoberta de arquivos

Escaneia input/ por arquivos *.pdf em ordem alfabética. Se nenhum for encontrado, exibe aviso e encerra.

2
Dupla abertura do PDF

fitz.open() é usado para extração de texto (pesquisa de CPF/CNPJ); pypdf.PdfReader é usado para escrita dos PDFs de saída. Ambas as bibliotecas são abertas sobre o mesmo caminho de arquivo.

3
Agrupamento por identificador

Para cada página, ExtractorIdentifier.extract() aplica as regras de negócio (veja src/identifier.py) e acumula os índices de página por chave de identificador.

4
Escrita dos PDFs de saída

Para cada grupo, um novo PdfWriter copia as páginas e grava output/<identificador>.pdf. O nome do arquivo usa o valor formatado (ex.: 123.456.789-00.pdf).

5
Relatório de lote

Log com total de arquivos gerados, timestamp de início/fim e tempo decorrido (via perf_counter).

Fase 2 — Envio de E-mails

1
Descoberta de arquivos de saída

Utiliza os arquivos gerados pela Fase 1 (se executadas juntas) ou re-escaneia output/.

2
Conexão com Oracle

Instancia OracleDB e consulta get_account(id_number) para obter nome e email do destinatário.

3
Renderização do template HTML

O EmailSender carrega templates/informe.html e substitui $customer_name, $company_name e $ano_atual.

4
Envio via AWS SES

Monta mensagem MIME multipart, anexa o PDF e chama ses_client.send_raw_email(). Em modo teste, o destinatário é sobreescrito por EMAIL_TESTE.

5
Movimentação de arquivos

Sucesso → sent/success/. Falha → sent/failure/. Resumo final exibe contadores de enviados, não encontrados e erros.

Interface CLI

O ponto de entrada é sempre python main.py com um ou mais argumentos.

python main.py [--split] [--send]
ArgumentoAliasDescrição
--split --processar Executa a Fase 1: divide os PDFs de input/ por CPF/CNPJ e grava em output/.
--send --enviar Executa a Fase 2: envia os PDFs de output/ por e-mail via AWS SES.

Exemplos de uso

# Apenas dividir os PDFs
python main.py --split

# Apenas enviar e-mails (PDFs já processados em output/)
python main.py --send

# Pipeline completo: dividir e enviar em sequência
python main.py --split --send

# Exibir ajuda
python main.py --help
⚠
Se nenhum argumento for fornecido, o programa exibe o texto de ajuda e encerra com código de saída 0.

Módulo: main.py

Ponto de entrada e orquestrador das duas fases do pipeline.

split_pdfs() → list[Path]

Descobre PDFs em INPUT_DIR, instancia PDFProcessor e itera sobre cada arquivo, acumulando os Path dos arquivos gerados. Registra resumo de lote com timestamps e tempo total.

Retorno
Lista de Path apontando para os PDFs criados em output/.
Efeitos
Escreve arquivos em disco; registra logs; encerra com sys.exit(0) se não houver PDFs.
enviar_emails(files) → None

Recebe uma lista de arquivos (ou re-escaneia OUTPUT_DIR), instancia OracleDB e EmailSender e itera, consultando o Oracle e enviando o e-mail para cada destinatário.

Parâmetro
files: list[Path] | None — se None, usa output/*.pdf.
Efeitos
Move PDFs para sent/success/ ou sent/failure/; registra contadores.

Módulo: src/pdf_processor.py

class PDFProcessor

Orquestra a divisão de um PDF em arquivos individuais por CPF/CNPJ.

Construtor
PDFProcessor(output_dir: Path)
PDFProcessor.process(caminho_pdf) → ProcessingResult

API pública. Abre o PDF com fitz e pypdf, chama _group_pages() e depois _write_groups(), retornando um ProcessingResult com estatísticas completas.

PDFProcessor._group_pages() → dict[str, PageGroup]

Primeiro passo: varre cada página com fitz, extrai o identificador e acumula índices. Páginas sem CPF/CNPJ herdam o identificador da página anterior; a primeira página sem identificador gera um nome pagina_N_sem_identificador.

@dataclass ProcessingResult
total_pages
Total de páginas no PDF de entrada.
groups
Lista de PageGroup gerados.
generated_files
Caminhos dos PDFs escritos em output/.
started_at / finished_at
Timestamps de início e fim.
elapsed_seconds
Tempo de processamento em segundos.
total_files
Propriedade calculada = len(generated_files).

Módulo: src/identifier.py

Extrai CPF ou CNPJ de um bloco de texto seguindo regras de negócio específicas para informes de rendimento.

Regras de negócio

SituaçãoAçãoTipo resultante
≥ 2 CNPJs na página Usa o 2.º CNPJ (empresa destinatária) CNPJ
Exatamente 1 CNPJ Ignora o CNPJ; tenta usar o CPF da página CPF
0 CNPJs Usa o primeiro CPF encontrado CPF
0 CNPJs e 0 CPFs Retorna Identifier vazio (falsy) —

Padrões Regex

# CNPJ: XX.XXX.XXX/XXXX-XX (aceita espaços/pontos opcionais)
_CNPJ_RE = re.compile(r"\b(\d{2}[.\s]?\d{3}[.\s]?\d{3}[/\s]?\d{4}[-\s]?\d{2})\b")

# CPF: XXX.XXX.XXX-XX (aceita espaços/pontos opcionais)
_CPF_RE  = re.compile(r"\b(\d{3}[.\s]?\d{3}[.\s]?\d{3}[-\s]?\d{2})\b")
ℹ
Após a correspondência regex, os dígitos brutos são validados pelo comprimento (14 para CNPJ, 11 para CPF) antes de ser formatados. Isso filtra falsos positivos de sequências numéricas similares.
@dataclass Identifier
valor
CPF/CNPJ formatado (ex.: 123.456.789-00).
tipo
"CPF", "CNPJ" ou "---".
nome_arquivo
Propriedade: valor com caracteres inválidos do Windows substituídos por _.
__bool__
Retorna False se valor for vazio.

Módulo: src/database.py

Camada de acesso ao Oracle usando oracledb em modo thin (sem Oracle Client instalado localmente).

class OracleDB

Gerencia uma conexão persistente com cursor, reconectando automaticamente via ensure_connection() quando necessário. Suporta uso como gerenciador de contexto (with OracleDB() as db).

OracleDB.get_account(registration) → dict | None

Recebe CPF/CNPJ com apenas dígitos e retorna um dicionário com ao menos as chaves nome e email, ou None se não encontrado.

OracleDB.executar(query, params) → list[dict]

Executa qualquer query e retorna lista de dicionários com chaves em minúsculo (coluna: valor), facilitando acesso por nome de coluna sem depender de índices numéricos.

OracleDB.testar_conexao() → bool

Executa SELECT 1 FROM DUAL para verificar conectividade. Útil para health-check antes de iniciar o lote de envios.

Segurança

⚠
Esta seção cobre as principais considerações de segurança do projeto. Revise-as antes de implantar em produção.
ÁreaPrática adotadaRecomendação adicional
Credenciais Carregadas via .env / variáveis de ambiente. Em produção, use AWS Secrets Manager ou Vault; nunca versione .env.
Oracle SQL oracledb usa bind parameters (params). Certifique-se de que todas as queries utilizam :param e nunca f-strings com entrada do usuário.
Injeção de e-mail Destinatário vem do Oracle, não de input externo direto. Valide o formato de e-mail (re ou email-validator) antes do envio.
Anexo PDF Apenas arquivos gerados internamente são anexados. Confirme que attachment.exists() antes de ler (já feito em _build_message).
Modo teste MODO_TESTE=true redireciona todos os e-mails. Habilite sempre em ambientes de homologação para evitar envio acidental a clientes reais.
Dados PII CPFs/CNPJs aparecem nos nomes de arquivo em output/. Restrinja permissões da pasta output/ e sent/ ao usuário de serviço.

Tratamento de Erros

CenárioComportamentoResultado
Nenhum PDF em input/ Log de aviso + sys.exit(0) Encerramento limpo.
Arquivo PDF não encontrado (ao processar) FileNotFoundError lançado por PDFProcessor.process() Exceção propagada; interrompe o lote.
Página sem CPF/CNPJ Herda identificador anterior ou gera nome pagina_N_sem_identificador PDF separado criado; log de aviso.
CPF/CNPJ não encontrado no Oracle Log [N/F], incrementa not_found PDF ignorado; continua para o próximo.
E-mail ausente no Oracle Log [S/E], incrementa not_found PDF ignorado; continua para o próximo.
Falha no envio SES Log [ERRO], PDF movido para sent/failure/ Continua para o próximo destinatário.
Falha de conexão Oracle Exceção propagada de OracleDB.__connect() Interrompe a fase de envio.
Template HTML não encontrado FileNotFoundError em EmailSender.__init__ Interrompe antes de qualquer envio.
